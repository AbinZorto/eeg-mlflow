This study demonstrates that low-montage resting-state EEG can support patient-level prediction of remission outcomes in a home-based tDCS trial using an extremely sparse feature-selection framework. The strongest model achieved meaningful discrimination while selecting only a small set of recurrent features.

Rather than relying on high-dimensional feature spaces, the results suggest that compact and interpretable biomarker candidates centered on temporal entropy and frontal-temporal interactions may capture clinically relevant signal. These findings extend prior PSD-based analyses in the same cohort and support a convergent regional signal interpretation.
